# Trending Copyright-Free Music Library

Place any royalty-free / copyright-free `.mp3` or `.wav` backing tracks in this folder!

The YouTube Children's Cartoon Music pipeline will automatically detect and loop/adapt your audio files to match the song duration.

### Recommended Sources for Free Kids Music:
1. **YouTube Audio Library** (In YouTube Studio -> Audio Library):
   - Genre: Children's
   - Mood: Happy / Bright / Funky
   - 100% copyright-free and cleared for monetization on YouTube!
2. **Pixabay Music** (`https://pixabay.com/music/search/kids/`):
   - Free for commercial use, no attribution required.
3. **Incompetech (Kevin MacLeod)**:
   - Cheerful cartoon & preschool instrumental themes.

### File Naming Conventions (Optional):
- `trending_pop_upbeat.mp3`
- `bounce_playful.wav`
- `lullaby_gentle.mp3`

If this folder is empty, the autonomous procedural **Trending Kids Pop Synthesizer (124 BPM, Ukulele, 4-on-the-Floor Kick, Claps & Glockenspiel)** will automatically generate high-energy backing tracks with zero external dependencies!
